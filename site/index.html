给盲人用的语音手机助手

BlindPilot 让盲人用户用说话来完成手机任务：听到简洁进度，随时本地停止， 危险动作必须确认，密码和验证码永远不会交给云端。

这是一个开源项目。Android 无障碍服务在手机上执行动作，云端 Agent 只能通过经过校验的工具来建议下一步。

它做什么

  • 用语音发起任务，用语音听到结果。
  • 读取屏幕上的按钮和文字，按语义节点点击，而不是乱点坐标。
  • 和 TalkBack 共存，不取代系统读屏。
  • 不需要 Root，不需要 Shizuku，不需要电脑 ADB。
  • 紧急停止在手机本地生效，即使服务器断开。

停止口令：停止、取消、别动、停下来。

隐私

  • 密码、支付密码、验证码、卡片安全码标记为 SECRET，序列化时变成 [PROTECTED]。
  • 截屏默认只留在内存，不保存到相册，也不会作为默认感知方式。
  • 手机私钥生成在 Android Keystore，不会打进安装包，也不会上传。
  • 不会把完整聊天记录交给云端 Agent。

安全策略

SafetyEngine 是确定性程序，不是模型提示词。模型只能提议，能不能做由策略决定。

  • GREEN：打开应用、返回、桌面、滚动、读屏。可以自动执行。
  • YELLOW：发消息、打电话、改普通设置。必须口头确认。
  • RED：转账、购物、卸载、恢复出厂。第一版直接拒绝。
  • SECRET：密码类内容永不交给 Agent。

这台服务器

当前站点域名：freus.cn。接口前缀 /v1/，健康检查：

  • /health/live — 进程存活
  • /health/ready — 就绪（不要求 Agent 在线）
  • /v1/status — 公开状态

运行时云端 AI 只接 Antigravity Agent。没有 Gemini generateContent 回退，也没有 OpenAI / Grok / Anthropic 运行时。

安装（给家属）

当前是调试版，只给信任的人安装。Android 12 及以上。不需要 Root，不需要电脑。

  1. 下载调试包： Andclaw.apk （约 16 MB）。SHA-256： 4675FE7628B8570D8E8B27FE3E45AE12543164C30D483523251C4D0E1E00091C
  2. 在系统设置里允许安装未知来源的应用，然后安装这个 APK。
  3. 打开「设置 → 无障碍」，启用 BlindPilot / Andclaw 无障碍服务。TalkBack 用户可以在应用列表里听到说明。
  4. 回到应用，打开「BlindPilot 无障碍核心」。先不要连云端 AI。
  5. 依次试：朗读屏幕、点击、长按、输入、滚动、返回、桌面、打开设置、打开时钟、截屏（只留在内存）。
  6. 点「本地停止」后再点点击，应该被拒绝。这是给盲人用户的紧急刹车。

语音发起任务属于后续里程碑。现在先保证每一步动作在没有 AI 时也能完成，而且停得住。
