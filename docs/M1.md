## Regression risks

- Andclaw `AgentController` LLM loop was not edited.
- Coordinate gestures remain as fallback; TalkBack explore-by-touch may still fight `dispatchGesture`.
- App launch uses launcher intents only. Arbitrary `tel:` / `http` is rejected.
- Screenshot path in the harness does not write MediaStore. Andclaw Action Test “截屏并保存” still does.

## Acceptance

Manual, TalkBack on:

1. Observe reads nodes and does not speak password plaintext.
2. Click / long-click / set-text / scroll / swipe / Back / Home / open Settings / screenshot succeed with the service enabled.
3. Local stop then click → rejected.
4. `./gradlew :app:testDebugUnitTest` and `pytest` in `server/` pass.
